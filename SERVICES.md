Clear, sellable packages tied to real small-business pain points.

## 1. Website Redesigns (Core Offer)

| Package | What's Included | Price Range |
|---------|-----------------|-------------|
| **Concept Only** | Free redesign mockup (HTML) | $0 (lead magnet) |
| **Starter Site** | 5–7 page mobile-first site, easy content updates, basic SEO, training | $2,800 – $3,400 |
| **Full Custom** | Strong brand design, local SEO, Google Business alignment, owner training, 30-day support | $3,500 – $4,500 |

## 2. Easy Update Systems + Light Maintenance Retainers

**Goal:** Solve the "I don't have time / I don't know how" problem.

- Hand off a site the owner can actually change (menu, hours, photos).
- 30–60 minute training session included with every paid build.
- Optional monthly retainer so small changes don't require a new project quote.

**Retainer menu (examples):**
- Hours / specials updates
- New photo swaps
- Seasonal menu PDF or page updates
- Broken link / speed checks

**High-ROI, relatively fast deliverable.**

| Item | Details |

| Consistency check | Address/phone/name across major directories |
| Review strategy | Simple request system (QR or link) |

| **Package price** | $600 – $1,200 (standalone) or $400–$800 as add-on to a website project |

This is an easy upsell after showing a free mockup.

## 4. Simple Automation for Local Businesses

Start small. Focus on time-savers owners actually feel:

| Automation | Tools | Value |
|------------|-------|-------|
| Review request after visit / order | Make.com or n8n + email/SMS | More 5-star reviews |
| New lead → CRM / email sequence | Make / n8n + Google Sheets or email | No leads fall through cracks |
| Social content recycling | SocialBee / Make | Consistent presence without daily work |
| Booking / inquiry confirmation | Forms + email/SMS | Professional, fewer no-shows |

**Positioning:** "I set up simple systems so you spend less time on admin and more time on the business."

Pricing guidance:
- One-time setup: $400 – $1,200 depending on complexity
- Optional light monitoring retainer: $50 – $100 / month

---

## Recommended Sales Path

1. Send free concept mockup (Depot, Millie's, etc.).
2. Offer Starter or Full Custom site.
3. Add Google Business package as an easy yes.
4. Offer monthly care + simple automations once the site is live.

This turns a one-time project into a relationship and recurring revenue.
